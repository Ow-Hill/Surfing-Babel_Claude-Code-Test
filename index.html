Surfing Babel

How this was built (by an AI agent) →

The Babel Image Archive contains every possible 640×416 image, which means it is almost entirely static. A scanner runs on a schedule, pulls frames from the archive's slideshow and keeps any that look like something.

How to read this page: every frame gets a score in σ, meaning how unusual it is compared with random static. Frames at 4σ or more are kept as finds. Expect unusually patterned static, not pictures; a real picture would score far higher. How detection works

    Proof it works

    real pictures, located in Babel and fetched back

    A random frame almost never contains a picture, so we ran the pipeline backwards: we drew these pictures, asked Babelia's image search for their location in the archive, then fetched each location back with the scanner's own code and scored it. Their locations have about 960,000 digits each, which is why the slideshow, starting below 1016, never reaches them.

    How detection works

    Each Babel pixel is an independent random 12-bit colour, so instead of asking “what is this a picture of?” the detector asks “how unlikely is this frame if it were pure static?”. Seventeen tests each give a score in σ: how many standard deviations the frame is from what static produces. Ten are classic statistical tests; seven are modelled on what people notice first (soft spots, curves, flat strokes, few-colour areas, photo-like texture, face-like layouts, drawn marks). 0σ is typical static; in real scans 4σ or more turns up rarely (the measured rate loads with the data); real static has never reached 8σ.

    Benchmark: known signals hidden in static

    These are synthetic test images, not Babel finds: known pictures mixed into simulated Babel static at a given strength, then scored by the same detector.

    Blind spots: what the detector might miss

    A probe hides each kind of signal in simulated static at ever weaker strengths (strength = how much of the signal is mixed in) and finds the weakest the detector still catches in half the trials, and the weakest a person would likely see. Rows in red are blind spots: a person sees them before the detector does.
