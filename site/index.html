Surfing Babel

The Babel Image Archive contains every possible 640×416 image, which means it is almost entirely static. A scanner runs on a schedule, pulls frames from the archive's slideshow and keeps any that look like something.

How detection works

Each Babel pixel is an independent random 12-bit colour, so instead of asking “what is this a picture of?” the detector asks “how unlikely is this frame if it were pure static?”. It runs six statistical tests on brightness and both colour channels. Each test's result is measured in σ (standard deviations away from what static produces), calibrated on simulated static that uses Babelia's own JPEG encoding and checked against real frames.

shaperegions, gradients and large shapes that survive block-averaging (4–64 px)
blobsmall strong objects: the most extreme sliding window, 8–48 px
lineshorizons, stripes and bands: rows and columns, 1–8 px thick
textureneighbouring pixels that agree (smooth) or alternate (checkerboards)
palettecolour channels that move together (greyscale or limited palettes)
tonehistogram skew: too dark, too bright or too few colours
